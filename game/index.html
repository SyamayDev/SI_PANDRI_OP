          Bantuan & Tentang Game

          Cara bermain

          • Klik Lanjut, klik teks dialog, atau tekan Spasi/Enter/→ untuk melanjutkan. Dialog tidak pernah berjalan sendiri.
          • Di setiap misi, ikuti petunjuk pada panel. Tombol ? menjelaskan mengapa langkah itu perlu.
          • Jawaban keliru tidak menghentikan permainan; kamu mendapat penjelasan dan bisa mencoba lagi.
          • Progres tersimpan otomatis per bagian babak. XP hanya diberikan sekali untuk setiap misi.

          Mode Cerita dan Mode Presenter

          Mode Cerita: babak terbuka berurutan setelah misi selesai. Mode Presenter: semua babak dan bagian dapat dipilih langsung, kecepatan dialog dapat diatur, ada catatan presenter dan tombol tampilkan jawaban. Mode Presenter tidak mengubah save Mode Cerita.

          Tentang game ini

          SI-PANDRI (Sistem Pengelolaan Parfait Laundry) adalah aplikasi terminal Free Pascal. Game ini adalah media presentasi terpisah: simulasi di browser tidak menjalankan SI_PANDRI.exe, tidak mengubah file data aplikasi, tidak mengirim WhatsApp, dan tidak memproses pembayaran sungguhan. Semua nama pelanggan dan nomor di game ini fiktif. Tokoh Gilbert, Sarah, dan Syahril adalah maskot SEPAKAT; peran mereka di cerita adalah fungsi naratif.
